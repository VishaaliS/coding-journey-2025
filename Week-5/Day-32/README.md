## Key Realization

**You can memorize:**
- Two pointer (left, right, move inward)
- Sliding window (expand, shrink)
- Stack push/pop operations

**You CANNOT memorize:**
- Recursion

**Why?**  
Recursion requires understanding:
- What's the base case? (When does it stop?)
- What's the recursive case? (What does it trust?)
- How do they combine to solve the problem?

Without understanding, the code doesn't stick.

## What I Learned

**Lesson 1:** Can't shortcut recursion  
Need to build from fundamentals.

**Lesson 2:** Understanding > memorization  
Always. Especially for recursion.

**Lesson 3:** Need to go back to basics  
Master Fibonacci, Power, Climbing Stairs before structural recursion (linked lists).
